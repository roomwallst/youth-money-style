# Youth Money Style — 내 상황에 맞는 돈관리 스타일 찾기

## 2. 질문 15개 수정 방법

`questions.js` 를 메모장 또는 [VS Code](https://code.visualstudio.com/)로 엽니다.

```js
{
  id: 'Q2',
  text: '한 달에 필요한 생활비를 얼마나 알고 있을까?',   // ← 질문 문장
  options: [ ... ],
  hint: '...',        // (선택) 질문 아래 작은 안내 상자
  role: '...'         // 강사용 화면에 표시되는 문항 역할 설명

```

- `text` 의 따옴표 `' '` 안쪽 글자만 바꾸세요.
- 질문의 **순서와 개수(15개)는 바꾸지 마세요.** 점수 로직이 "Q3 = 세 번째 질문"처럼 순서를 사용합니다.

## 3. 선택지 수정 방법

같은 파일의 `options` 배열에서 4개의 문장을 바꿉니다. 순서는 항상 A, B, C, D이고 내부 점수는 A=0, B=1, C=2, D=3입니다.

```js
options: [
  '아직 잘 모르겠다',            // A = 0
  '대략 어느 정도인지 알고 있다', // B = 1
  '주요 지출 항목을 알고 있다',   // C = 2
  '항목별 금액까지 파악하고 있다' // D = 3
],
```

> 선택지 의미의 순서를 뒤집으면 점수 의미도 뒤집히니 주의하세요.
> 건너뛰기 버튼은 `skippable: true` 가 있는 문항(현재 Q5)에만 나타납니다.

## 4. 점수 로직 수정 방법

`scoring.js` 상단의 `RULES` 숫자만 바꾸면 기준이 바뀝니다.

```js
var Q7_SCORES = [0, 2, 2, 3];          // Q7 합리적 소비 점수 (B 가격 비교 = C 중고거래)
var Q6_HORIZON = ['short', 'mid', 'long', 'undecided']; // Q6은 점수가 아닌 구분값
var RULES = {
  prepareMaxP: 3,                                          // Q5 응답 시 P≤3 → 준비우선형
  gapMinT: 4,                                              // 위험 선호 T≥4 + 비상금 부족 → 준비 우선
  active: { T: 5, P: 6, H: 4, Q3: 2, Q4: 2, Q5: 2, E: 2 },  // 적극탐색형 최소 기준
  growth: { T: 3, P: 6, H: 3, Q3: 1, Q4: 2, Q5: 2, E: 1 },  // 성장탐색형 최소 기준
  stableMaxT: 2                                            // T≤2 → 안정중시형
};
var RISKY_FRAUD_ANSWERS = [0, 1]; // Q8에서 A, B를 고르면 사기 예방 안내 표시
```

### 영역별 점수

| 영역 | 계산 | 범위 |
|---|---|---|
| P 재정 준비 상태 | Q3 생활비 상황 + Q4 비상금 + Q5 부채 부담 (각 A0~D3) | 0~9 |
| H 금융생활 습관과 이해 | Q2 + Q7(A0·B2·C2·D3) + Q9 | 0~9 |
| T 위험 선호 성향 | Q11 + Q12 | 0~6 |
| D 자금 사용 시기 | Q6 — 점수가 아니라 구분: A 단기 · B 중기 · C 장기 · D 미정 | — |
| E 금융지식 학습 의향 | Q13 | 0~3 |

**재정 준비 상태(P)와 위험 선호(T)를 따로 판단한 뒤 결합**합니다. 전체 점수를 합산하지 않습니다.

### 분류 순서 (먼저 해당하는 유형으로 결정)

1. **준비우선형** — 다음 중 하나
   - Q3=A 생활비 마련이 어려움, 또는 Q5=A 연체·상환이 매우 부담
   - Q4=A 비상금 없음 이고 Q3≤B 생활비 여유가 거의 없음
   - Q5에 답했고 P≤3
   - 위험 선호 T≥4 인데 비상금이 부족함 (Q4=A, 또는 Q4=B 이고 Q3≤B)
   - *교육적 이유*: 생활비·연체·비상금 문제가 있으면 투자보다 현금흐름과 안전망이 먼저입니다. 위험을 감수하려는 마음이 커도 손실을 견딜 여건이 부족하면 생활이 흔들립니다.
2. **적극탐색형** — Q5 응답, Q6=C(장기), T≥5, Q3≥C, Q4≥C, Q5≥C, H≥4, E≥2 모두 충족
   - *이유*: 생활 안정·장기 목표·변동 감수 의향·학습 의지가 모두 있을 때만 배정. 추천 행동은 모두 손실 관리 중심입니다.
3. **성장탐색형** — Q5 응답, Q6=C(장기), T≥3, P≥6, Q4≥C, Q5≥C, H≥3, E≥1 모두 충족
   - *이유*: 기본 안전망과 장기 목표가 있으면 장기·분산투자 원리를 배우기 좋은 시기입니다.
4. **안정중시형** — T≤2
   - *이유*: 원금 보전·예측 가능성을 중시하는 성향 자체를 존중합니다.
5. **분산안정형** — 나머지 (위험 선호 중간 이상이지만 장기 목표나 준비 조건 일부가 아직 없음)

### 특별 처리

- **Q5 건너뛰기**: 0점(부채 부담 큼)도, 부채 없음도 아닙니다. Q3·Q4 평균값으로 자리를 채운 추정치를 쓰고, 성장·적극탐색형은 배정하지 않으며, 결과에 "일부 정보가 없어 참고용으로 분류했습니다"와 그 이유를 안내합니다.
- **Q6 미정(D)**: 그 자체로 준비우선형이나 낮은 점수가 되지 않고, 장기로도 보지 않습니다. 결과에 "언제, 무엇에 쓸 돈인지부터 정해 보기" 안내가 붙습니다. 단기(A)는 "가격 변동이 없는 곳에 모으기" 안내가 붙습니다.
- **비상금 보완**: T≥4 이고 비상금이 1개월 미만이지만 생활비 여유가 있어 분산안정형이 된 경우, 추천 행동 1번이 "비상금 목표 먼저 세우기"로 바뀌고 안내 문장이 추가됩니다(`results.js` 의 `gapAction`).
- **Q1 소득**만으로 유형이 정해지지 않습니다. Q3은 소득 출처(근로·가족 지원·모아둔 돈)와 무관하게 생활비 충당 여부만 묻습니다.
- **Q7**은 중고거래 경험이 아니라 필요성·예산·가격 비교 같은 소비 판단을 봅니다.
- Q8(사기 예방), Q10·Q14(설명 개인화), Q15(실천 행동 개인화)는 유형 점수에 쓰이지 않습니다.

```js
  title: '지금은 금융생활의 기초를 만드는 시기!',      // 한 줄 제목
  desc: ['문장1', '문장2'],                         // 설명 (2~3문장)
  actions: ['행동1', '행동2', '행동3'],              // 추천 행동 — 반드시 3개
  personalAction: { ... },                         // Q15 선택을 몇 번째 행동에 반영할지
  color: '#1F7F74', soft: '#E3F2EF',               // 대표색 · 연한 배경색
  icon: 'M12 21v-8 ...'                            // 아이콘 선 모양 (24x24 SVG 경로)
},
```

- **개인화 문장**: `CONCERN`(Q10 고민)과 `GOAL`(Q14 목표) 문구가 합쳐져 "요즘은 ○○이 가장 고민이고, ○○을 목표로 하고 있네요." 문장이 만들어집니다.
- **Q15 실천 행동 반영**: `personalAction` 의 `0~3`(A~D)마다 `{ index: 바꿀 위치, text: 새 문구 }` 입니다. `text: null` 이면 이미 같은 행동이 있으므로 문구는 두고 "내가 고른 행동" 표시만 붙입니다. 사기 예방·손실 관리 같은 안전 행동은 지워지지 않게 설계되어 있습니다.
- **사기 예방 안내 문구**: `FRAUD_NOTICE`, `FRAUD_TIP`
- 행동 문구는 이미지에서 잘리지 않도록 **30자 이내**를 권장합니다(테스트가 자동 확인).

## 6. 결과 카드 디자인 수정 방법

- **화면 색상·글꼴**: `styles.css` 맨 위 `:root` 의 변수 (`--navy`, `--gold` 등)
- **유형별 색상**: `results.js` 의 `color`, `soft`
- **저장 이미지(1080x1350)**: `card.js` 의 `CARD` 값(색·여백)과 `draw()` 함수의 글자 크기
  - 글이 길어지면 본문 글자 크기를 자동으로 최대 70%까지 줄여 이미지 안에 맞춥니다.
- **글꼴**: [Pretendard](https://github.com/orioncactus/pretendard) (SIL Open Font License 1.1, 무료·상업적 사용·재배포 가능).
  라이선스 전문은 `fonts/pretendard/LICENSE.txt`. 필요한 글자 묶음만 내려받는 방식이라 휴대폰 데이터 사용이 적습니다.
  폰트를 불러오지 못하면 기기 기본 글꼴(Apple SD Gothic Neo, 맑은 고딕 등)로 자동 대체됩니다.
  **GitHub에 올릴 때 `fonts` 폴더도 꼭 함께 올리세요.**
- 공식 로고 파일이 없어 텍스트 브랜드 "방구석월가"만 사용합니다. 로고를 넣고 싶으면 이미지를 프로젝트 폴더에 넣고 `index.html` 의 `brand-bar` 와 `card.js` 상단 바 부분을 수정하세요.

- 가상 참가자 사례 A~G 분류 결과 (`tests/cases.js`)

- 무작위 10만 건에서 다섯 유형 모두 등장
- 소득만으로, 위험 선호만으로 유형이 정해지지 않음

- 모든 유형 × 모든 Q15 선택에서 추천 행동 정확히 3개, 안전 행동 유지

## 8. GitHub 저장소 업로드 방법 (명령어 없이)

1. [github.com](https://github.com) 에 로그인 → 오른쪽 위 **+** → **New repository**
2. Repository name: `youth-money-style` / **Public** 선택 / 다른 옵션은 체크하지 않음 → **Create repository**
   (이미 같은 이름의 저장소가 있다면 다른 이름을 쓰세요. 기존 저장소를 덮어쓰지 않도록 주의)
3. 만들어진 페이지에서 **uploading an existing file** 링크 클릭
4. `youth-money-style` 폴더 **안의** 파일과 폴더를 모두 선택해 브라우저 창으로 끌어다 놓습니다.
   - `index.html` 이 저장소 맨 위(최상위)에 있어야 합니다. 폴더째 올려 `youth-money-style/index.html` 이 되면 안 됩니다.
   - `node_modules`, `e2e-shots` 폴더가 있다면 올리지 않아도 됩니다.
   - `.nojekyll` 처럼 점으로 시작하는 파일은 탐색기에서 안 보일 수 있습니다. 탐색기 **보기 → 표시 → 숨긴 항목**을 켜고 함께 올리세요.
5. 아래 **Commit changes** 클릭

> GitHub Desktop 프로그램을 쓰면 이후 수정본 업로드가 더 편합니다: File → Add local repository → 폴더 선택 → Publish repository.

## 9. GitHub Pages 배포 방법

1. 저장소 페이지 → **Settings** → 왼쪽 메뉴 **Pages**
2. **Build and deployment** → Source: **Deploy from a branch**
3. Branch: **main** / 폴더: **/(root)** → **Save**
4. 1~3분 뒤 같은 페이지 위쪽에 주소가 나타납니다.
   예: `https://내아이디.github.io/youth-money-style/`
5. 휴대폰으로 접속해 진단 끝까지 + 이미지 저장까지 한 번 해 보세요.

- 모든 경로가 상대경로라 `/youth-money-style/` 같은 하위 주소에서도 정상 동작합니다.
- 파일을 수정해 다시 올리면 몇 분 뒤 자동 반영됩니다. 휴대폰에서 예전 화면이 보이면 새로고침하세요.
- 저장소를 Public으로 만들면 코드도 공개됩니다(수강생 응답은 어디에도 저장되지 않으므로 응답이 공개되는 일은 없습니다).

## 10. 배포 URL로 QR코드 만드는 방법

- **Chrome / Edge (가장 간단, 무료·광고 없음)**: 배포 주소를 연 상태에서 주소창 오른쪽의 **공유 아이콘 → QR 코드 만들기** → **다운로드**
- 또는 네이버 QR코드 등 QR 생성 서비스를 이용할 수 있습니다. 일부 서비스는 단축 URL을 거치거나 일정 기간 뒤 만료되니, **원래 주소가 그대로 들어간 정적 QR**인지 확인하세요.

강의 운영 팁
- QR 아래에 짧은 주소도 함께 적어 두세요(QR이 안 읽히는 기기 대비).
- 카카오톡 QR 스캐너로 열면 카카오 내부 브라우저에서 열립니다. 이미지 저장 화면에서 **이미지를 길게 눌러 저장**하면 됩니다.
- 시작 전 "정답이 없는 자기이해 활동이고, 결과에 우열이 없다"는 점을 한 번 짚어 주시면 좋습니다.
